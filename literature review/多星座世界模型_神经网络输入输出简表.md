# 多星座宽带阵列世界模型：输入、输出与切换简表

采用**结构化世界模型 + 滚动规划**：网络预测未知干扰，轨道、链路和切换状态机显式计算，规划器选星并决定切换时机。服务采用满缓冲连续速率模型，不维护业务队列。先以 A 为本方、B 为外方；L1/L2 中仅 A 训练，B 使用固定规则或冻结控制器，L3 才让各学习方分别更新模型/控制器。

**场景为 array-based broadband LEO：定向阵列宽带终端，首版固定终端，不采用手机 DTC。** 被调度用户使用一个完整宽带信道；不同方向用同频多波束空间复用，同波束用户按时间轮询，不做逐 RB 分配。全带宽指单个用户信道，而不是卫星所有频段和极化的总频谱。

**渐进范围：第一篇可以只做 L1，或做 L1+L2；L3 留作后续。**

| Level | 外方 B 的行为 | 本方 A 要预测什么 | 研究阶段 |
| --- | --- | --- | --- |
| **L1：外生变化** | 按覆盖等固定规则换星和发射，不因 A 的干扰调整 | 外方有效功率及持续性；不同 A 计划可复用同一 B 源轨迹 | 首篇基本范围：历史预测与多步规划的服务收益 |
| **L2：固定规则响应** | 用延迟信号测量、门限、计时器和驻留规则响应，规则不更新 | A 行动引起的 B 响应及后续干扰；各计划分别演化 B | 首篇可选增强：动作条件预测、响应时序与振荡改善 |
| **L3：多方学习** | A/B 在采集批次之间更新参数，批次内冻结 | 不同对手版本下的响应分布 | 后续研究：对手池、分轮更新与交叉版本测试 |

**起步配置：** 控制周期 Δ=1 s，历史 W=30 s，预测 H=30 s；共享卫星 MLP 宽度 64，集合表示 128 维，RSSM 记忆 h=256 维、随机潜状态 z=32 维。本方候选最多 K=4，保留当前星和准备目标；这个上限不截断外方干扰源。各卫星共用一个模型。

**合成链路配置：** 中心频率 20 GHz，单信道 B=250 MHz、单极化；接收16×16阵列，物理间距为中心频率半波长。每星所研究信道最多 M_co=8 个同时数据波束，每波束标称10 W、每星总射频预算80 W（含导频/控制），按固定规则分摊；波束内按50 ms轮询。宽带速率用5个频率求积点计算，求积点是物理数值计算，不是调度资源。这些是实验参数，不是某商用系统的真实规格。

| 模块 | 输入 | 输出与用途 |
| --- | --- | --- |
| **已知几何** | 已发布星历及其时间戳、UE 位置、服务资格与设备配置 | 传播得到历史/未来位置，解析计算方向、距离、可见时间、路径损耗、传播时延与基准信号 |
| **历史编码** | 已到达的 S_ref、J、SINR、噪声校准；测量信道/极化/频谱、方向、时间与掩码；已发动作、已到达控制确认和本方波束/时间/功率账本 | 当前记忆 h 与潜状态 z 的后验分布；未确认动作保留 pending |
| **RSSM 递推** | h/z、公开几何、子步时长；L2/L3 再加入已生效的本方行动/状态 | 下一步 h 与 z 的先验分布，预测未知外方活动与响应 |
| **学习输出头** | h/z、UE—卫星几何、信道配置；本方信号预算使用本方已知发射参数 | 外星全部活动同信道波束的全带宽入射功率 q 的联合分布；可选本方信号残差 δS（首版固定为 0），无逐 RB 输出轴 |
| **解析链路与协议** | 功率样本、频率相关阵列响应、全信道波束功率/时分安排/噪声配置、传播及处理时延、合法动作与控制确认 | 功率谱与全信道 S/I/N、SINR频谱、宽带连续速率 R、累计服务量 D、断流及可用服务窗口 |
| **训练** | 合法历史与随后实际到达的信号测量 | 测量似然 + KL + 未来测量自由展开；不训练速率或累计服务量输出头 |
| **滚动规划** | 保持、准备、等待、取消、执行等合法计划及联合预测轨迹 | 比较 D、切换/信令代价与长中断风险，选择目标和行动时机 |

**测量与功率：** S_ref 为导频功率，J=I+N；两者用 dBm，SINR 用 dB，噪声校准 N 用 W。测量须注明信道/极化、中心频率、测量带宽与参考频谱、采样与到达时间、方向，以及 valid/new/detected/missing 掩码；仅同化已到达报告。单 RF 每秒最多扫描一个候选，缺测值保留掩码与年龄。S_ref 按导频/数据功率与频谱配置换算为数据 S；纯 I 只能在线性域由 J−N 校准估计。

**几何与学习边界：** 位置用 m，速度用 m/s，方向用 rad，带宽与载频用 Hz。距离 d 决定 FSPL=20log₁₀(4πdf/c)（dB）和一程时延 d/c（s）；未来几何由可用星历传播，不读取未来真值。q 为每个 UE—外星的非负全信道入射功率（W），聚合该外星所有相关活动波束，已含传播损耗、尚未乘本方接收增益。按已声明的平坦发射谱与频率相关 FSPL 构造归一化 φ(f)，qφ(f) 用 W/Hz；φ不重复附加传播损耗。逐星 q 用实际测得的聚合干扰约束，无需逐星真值标签；δS 用 dB。所有候选、频点和本方UE共享联合潜轨迹。

**宽带连续服务与仿真：** 各频率点以功率谱密度计算 Γ(f,t)=S_psd/(I_ext,psd+I_own,psd+k_BT₀F)。实际频率相关阵列增益乘入信号和干扰，本方同星其他数据波束也计入干扰。R(t)=m(t)η∫_F log₂(1+Γ(f,t))df，η固定为1，R用bit/s；D=∫R(t)dt，用bit。m是实际被调度、连接与接收指向正确的二值掩码：切换/测量/恢复断流或其他用户占用时为0，准备期间可继续旧链路。不能先平均SINR再算速率。发射区间包含波束ID、信道/极化、全信道功率，经d/c映射为接收窗口；不生成数据包、逐块解码、重传或去重。D仅用于规划和独立评估，不作为网络输入、训练监督或学习输出头。

**负载与容量：** 输入本方已连接数、逐波束关联与时间份额、预留、活动波束及实际功率/余量；负载通过实际时分掩码、功率分摊和同频干扰改变服务。N_stream≤M_co，而N_connected可以更大；若每人必须持续同时独占全信道，则人数还受空间兼容和功率限制。外方私有用户数/位置/调度表不输入，未知负载的作用由q及响应潜状态表达。商用波束数量、同信道复用和虚拟波束的区别见详细方案第12节。

**多步规划：** 从当前后验按计划递推 h/z 和解析协议状态，直到 n+30；按事件拆分子区间，动作生效前不提前改变功率，不读取真实未来报告。下一秒有新报告到达后更新后验并重规划，只执行当前一步。正常分支至多一次切换，接通后保持至窗尾；运行时采用最小驻留10 s、净收益门限持续2 s、返星冷却20 s，并保留绝对准备/执行期限。失联或即将失去覆盖触发紧急恢复；低速率门限初值10 Mbps/持续3 s，以1 s平均服务尺度处理正常轮询。速率由已到达测量、声明频谱模板和已知时间安排解析估计，缺测、过旧或速率回升时重置计时器。传播、上报、计算与执行时延分别计算。主版使用GRU-RSSM + MPC，PPO只作同信息基线。

各 level 场景、A/B 算例、代价定义与训练流程见[详细研究方案](多星座对等共存_历史观测世界模型与预测切换_详细研究方案.md)。
